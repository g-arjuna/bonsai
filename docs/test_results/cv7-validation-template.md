# CV7 validation result template

This is the shape `scripts/ops/rebuild_and_validate.sh` writes each run.
File name: `docs/test_results/cv7-validation-<UTC-ISO>.md`.

Side-channel full logs live alongside in
`docs/test_results/cv7-validation-<UTC-ISO>.logs/` — one log per build/test/
inject command. On any FAIL, Mac side should pull and inspect those.

After every Ubuntu validation iteration the script commits + pushes the
populated file (and the .logs/ directory) so Mac picks them up via
`git pull origin main` and plans the next iteration from concrete evidence.
