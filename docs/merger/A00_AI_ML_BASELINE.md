| **1. Conformal calibration on clean scores claims anomaly coverage** | `python/bonsai_ml/gnn/conformal.py` lines 119–166, 197–213 | `calibrate()` filters `clean_scores = scores_np[labels_np == 0]` and sets `threshold` to the `1 - alpha` quantile of clean scores, while `coverage_interval()` returns `"coverage_guarantee": 1.0 - a` and docstring claims a target false-negative rate (`alpha`) for anomaly recall. | **3. Furthermore, `build_hetero_data()` only sets `node_ids` on `"device"`. | **A02**: Populate deterministic `node_ids` for all node types and `snapshot_ns` in `build_hetero_data()`.
